# Universal Linux Installer

Publieke TEST-release van de Universal Linux Installer.

## Installatie v1.1.0-bash.3 (TEST)

Download de bootstrap en de bijbehorende checksum:

    curl -fL https://github.com/jantodjamin-lab/linux-server-installer/releases/download/v1.1.0-bash.3/bootstrap.sh -o bootstrap.sh
    curl -fL https://github.com/jantodjamin-lab/linux-server-installer/releases/download/v1.1.0-bash.3/BOOTSTRAP.sha256 -o BOOTSTRAP.sha256
    sha256sum -c BOOTSTRAP.sha256
    bash bootstrap.sh

Deze versie is uitsluitend bedoeld voor testen. Volledige installatie op een VPS is nog niet gevalideerd.
